# MojeNowe

Prosta wyszukiwarka kanałów i grup Telegram (frontend bez backendu).

## Jak uruchomić

1. Otwórz `index.html` w przeglądarce.
2. Wpisz frazę wyszukiwania i użyj filtrów typu oraz języka.

## Co dalej?

- Podpiąć Telegram API / własną bazę kanałów.
- Dodać ranking, tagi i moderację zgłoszeń.
- Wdrożyć backend (np. Node.js + PostgreSQL).
